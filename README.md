# QPad

**A simple and lightweight Windows text editor.**

QPad is a desktop text editor built with Python and PySide6. It provides a clean and simple interface for everyday text editing.

## Features

- Create new text documents
- Open existing text files
- Edit and save documents
- Track unsaved changes
- Word and character count
- Line and column position indicator
- Keyboard shortcuts
- Simple and clean interface

## Download

Download the latest Windows installer from the [Releases](../../releases) section.

**Current Version:** 1.0.0

## Installation

1. Download `QPad-Setup-1.0.0.exe`.
2. Run the installer.
3. Follow the installation instructions.
4. Launch QPad from the Start Menu or desktop shortcut.

## System Requirements

- Windows 10 or later
- No separate Python installation required
